# JFiles
Free static website for guitar and piano chords/sheets.

## Run
Open `index.html` in any browser.

## Publish free
Upload `index.html` to a GitHub repository and enable GitHub Pages in Settings → Pages → Deploy from branch → main → / (root).

## Customize
Edit the `songs` array near the bottom of `index.html` to add your own authorized/original song entries.

Important: only publish lyrics, sheet music, tabs, or arrangements that you created, licensed, or are otherwise permitted to distribute.
